# 资源字段和更新规则

编辑 data/resources.json，数组中每个对象是一条独立资源。目前100条，分类可交叉，不能把各分类数量相加当作唯一总数。

| 字段 | 用途 |
| --- | --- |
| id | 稳定唯一ID，沿用RES-加编号，更新时不重排 |
| name | 资源实际名称 |
| form | 形式，如网站、官方文档、课程、文章教程、公开代码项目 |
| category | 一致的主题分类标签 |
| description | 简短概括，新增条目建议30至60字，不写未经核验的效果承诺 |
| url | 原始资源的直接HTTP或HTTPS链接 |
| author | 作者或机构，未知时如实记录 |
| language | 中文、英文、双语等，与实际内容一致 |
| access | 原站获取条件：免费、部分免费、付费、未明确 |
| accessNote | 登录、费用、原站使用条件和特殊情况说明 |
| updated | 来源页面日期；无日期时写未标明，不用今天替代 |
| status | 已核验页面、仅搜索摘要待核验、需登录、访问受限、链接失效 |
| license | 原资源明确显示的许可信息；没有则写未明确 |
| selectedLibraries | 所属资源库数组，支持交叉分类 |
| sourceHost | 原链接主机名，用于域名及GitHub分类 |
| siteAccess | 本站导航访问权限，本版本统一free，与原站access字段含义不同 |
| networkType | magic-maybe、unverified或direct-try等展示状态 |
| networkHint | 据实描述访问条件，不等于实测网络连通性 |

当前所属资源库标签：AI教育资源、WorkBuddy教学、豆包工作教学、千问办公教学、百度搭子教学、AI资讯资源。GitHub项目根据链接域名生成独立视图，不复制数据。

## 新增或更新

1. 先搜索名称和规范化URL，判断是否已有记录。
2. 既有资源修改简介、状态或分类，保留原ID。
3. 新资源分配未使用ID，删除资源后也不要回收编号。
4. 转载优先追踪原始来源。仅标题相同而内容独立时不要合并。
5. 保留来源更新日期和实际核验依据；需要记录新一轮采集日期时，可以新增collected字段，但不要替换updated的含义。
6. 构建会检查字段、ID、基本URL、重复链接和免费导航状态，但不会访问外部网站，不能据此声称链接已在线核验。

这份公开数据是展示字段子集，没有原Excel的行号、个人筛选批注、内部记录或发现渠道全表。原始采集工作簿继续本地保管，用于后续复核。
